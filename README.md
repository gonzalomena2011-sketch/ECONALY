# ECONALY — Financial Intelligence & Economic Research

A free, static website starter for an independent student-led finance, economics, and technology research project.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation and compound-growth calculator

## Run locally on Windows
1. Install Visual Studio Code.
2. Extract this folder.
3. In VS Code, choose **File → Open Folder** and select the `FINOVA` folder.
4. Open `index.html` in your browser (double-click it in File Explorer).
5. Edit the files in VS Code, save, then refresh the browser.

No Node.js, paid extension, or build process is required.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named `finova` (or another name you prefer).
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the deployment to finish and use the site URL shown in Pages settings.

GitHub Pages sites are public. Do not upload private information, passwords, personal financial data, or unpublished sensitive material.

## Research integrity
- The chart in the hero is illustrative, not live data.
- The research entries are planned topics, not completed studies.
- Cite the original source and publication date for every real dataset.
- Explain methodology, assumptions, limitations, and any corrections.
- This site is educational and does not provide personalized investment advice.

## Zero-cost note
The website uses plain HTML, CSS, and JavaScript. Google Fonts is an optional externally loaded font; if offline, fallback fonts are used. You can remove the Google Fonts links in `index.html` for a fully self-contained font setup.
